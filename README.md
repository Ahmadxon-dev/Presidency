# Presidency
MERN Stack App

This platform is a school management system with gamification and resource booking features. It allows administrators and teachers to manage users, classes, events, and news, while students can earn internal credits through academic performance and spend them on mock tests and school facility bookings.

📦 Tech Stack

    Frontend:
        * React
        * Redux Toolkit
        * Tailwind Css

    Backend:
        * NodeJS
        * Express
        * MongoDB
        * JWT 
        * Cloudinary

🧠 Features:
    * Authentication: login, registration
    * Role-based access control: Super Admin, Admin, Teacher, Student
    * User and class management: create, edit, and delete classes, users, and admins
    * Events and news management: create events, publish news, and register for events
    * Internal credit system: credits for verified academic performance
    * Internal credit Request: support multiple types of requests for internal credits
    * Resource booking with credits: use internal credits to book mock tests, the football court, and the e-sports room
